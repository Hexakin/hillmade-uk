# The Companion is hand-written, never generated from the private canon

The author's Novel repo (`WRO/characters/`, `worldbuilding/`, `glossary/`, `canon.md`) holds everything about the book, including events not yet published or not yet written. The Companion is therefore written as its own public content in this repo. Each entry and each fact carries a reveal chapter, and the author approves every entry. The site must never read, import, sync or generate from the canon files. A leaked spoiler can't be taken back, so we accept writing each entry twice in exchange for making a leak impossible by construction.

## Considered options

- **Generate Companion entries from canon at build time.** Rejected: one missing or mistaken reveal tag in a private file would publish a spoiler, and the canon files aren't written with a public reader in mind.
- **Hand-write the entries, with Claude drafting from canon for the author to approve.** Chosen. Drafting is a one-off editorial step; nothing automated connects the canon to the site.
